- 3D transformations (rotation, translation, scale)
- Lighting calculations using lighting matrices
- Perspective projection
- Clipping and culling
- Color and texture interpolation

Functions `FUN_overlay0__80020110` and `FUN_overlay0__8002106c` implement recursive polygon subdivision to:
- Improve visual quality of nearby objects
- Reduce texture distortion on large polygons
- Maintain adequate performance through adaptive culling

- GPU command buffers managed dynamically
- Stack system for recursive subdivision

### Optimizations
- Frustum culling to eliminate off-screen objects
- Z-sorting for depth ordering
- Culling based on size and distance
- Optimized GPU command generation
