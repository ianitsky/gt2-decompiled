4. System ready for use

1. `CdControl` → Sends command

4. Callbacks executed as necessary

### Pad Control Flow

3. `FUN_80087860` → Initializes port
4. `FUN_80087c84` → Sends/receives data

### MDEC Flow

1. `DecDCTReset` → Resets hardware
2. `DecDCTGetEnv` → Gets configuration
3. `DecDCTin` → Sends data
4. `DecDCTout` → Receives decoded data
5. `DecDCTinSync` / `DecDCToutSync` → Waits for completion
