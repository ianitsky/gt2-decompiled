## Módulo de Renderização de Polígonos

Este módulo contém funções relacionadas ao rendering de polígonos complexos usando o GTE do PlayStation 1, incluindo processamento de listas de polígonos, transformações de vértices, culling e geração de comandos GPU.

### FUN_80066ef8

**Linhas:** 2-138  
**Tipo:** `void FUN_80066ef8(int param_1, int *param_2, undefined4 param_3, uint param_4)`

**Descrição:**  
Processa uma lista encadeada de polígonos e gera comandos GPU para rendering. Esta função é otimizada para processar múltiplos polígonos em sequência, aplicando transformações GTE, realizando culling e gerando comandos tipo 5 (quadriláteros) no ordenador de polígonos.

**Parâmetros:**
- `param_1`: Ponteiro para estrutura de contexto de rendering
  - Offset 0x68: Ponteiro para buffer de comandos GPU (ordenador de polígonos)
  - Offset 0x98: Parâmetro de escala para cálculo de profundidade (ushort)
  - Offset 0x64 (100): Endereço base da tabela de texturas/cores (int)
  - Offset 0x398: Flag de inversão de culling (char)
  - Offset 0x3b0: Máscara de flags para rendering (uint)
- `param_2`: Ponteiro para lista encadeada de polígonos
  - Primeiro inteiro: Número de vértices no polígono atual
  - Seguintes: Dados do vértice (coordenadas X, Y, Z codificadas)
  - Último inteiro: Ponteiro para próximo polígono (0 se fim da lista)
- `param_3`: Parâmetro não utilizado (reservado)
- `param_4`: Coordenada Z de referência para cálculos de profundidade

**Processamento:**

1. **Loop Externo (Lista de Polígonos):**
   - Lê número de vértices do polígono atual (`*param_2`)
   - Processa polígono até encontrar ponteiro nulo (0) indicando fim da lista

2. **Transformação Inicial de Vértices:**
   - Carrega primeiros 3 vértices no GTE usando `gte_ldVXY0` e `gte_ldVZ0`
   - Aplica transformação perspectiva usando `gte_rtps_b()`
   - Extrai coordenadas Z dos vértices para cálculos de profundidade
   - Armazena flags de transformação (`gte_stFLAG()`)

3. **Loop Interno (Vértices do Polígono):**
   - Para cada vértice adicional (a partir do 4º):
     - Carrega vértice no GTE
     - Aplica transformação perspectiva
     - Armazena coordenadas de tela (`gte_stSXY0()`, `gte_stSXY1()`, `gte_stSXY2()`)
     - Lê valores de profundidade usando `read_sz_fifo4()`

4. **Cálculo de Profundidade:**
   - Determina vértice mais próximo ou mais distante baseado em flag
   - Aplica escala usando parâmetro de `param_1 + 0x98`
   - Calcula offset na tabela de texturas baseado em profundidade
   - Limita offset máximo a 0x3ffc (4092)

5. **Culling de Polígonos:**
   - Realiza back-face culling usando `gte_nclip_b()`
   - Verifica flags de transformação para polígonos inválidos
   - Aplica inversão de culling se flag `param_1 + 0x398` estiver setada
   - Usa operações bitwise para determinar visibilidade

6. **Geração de Comandos GPU:**
   - Se polígono for visível:
     - Gera comando tipo 5 (quadrilátero)
     - Configura flags de rendering (`0x28000000`)
     - Armazena coordenadas de vértices
     - Armazena ponteiros para dados de textura/cores
     - Escreve comando no buffer (`param_1 + 0x68`)
     - Incrementa ponteiro do buffer em 0x18 bytes (24 bytes por comando)

**Dependências:**
- Funções GTE:
  - `gte_ldVXY0`: Carrega coordenadas X, Y do vértice
  - `gte_ldVZ0`: Carrega coordenada Z do vértice
  - `gte_rtps_b()`: Aplica transformação perspectiva
  - `gte_stFLAG()`: Obtém flags de transformação
  - `gte_stSXY0()`, `gte_stSXY1()`, `gte_stSXY2()`: Armazena coordenadas de tela
  - `gte_nclip_b()`: Calcula normal para culling
  - `gte_stMAC0()`: Obtém resultado de cálculo
- `read_sz_fifo4()`: Lê valores de profundidade do FIFO do GTE

**Estrutura de Dados:**

**Lista de Polígonos:**
```
[contador] [v0_x] [v0_y] [v0_z] [v1_x] [v1_y] [v1_z] [v2_x] [v2_y] [v2_z] [v3_x] [v3_y] [v3_z] ... [próximo_polígono]
```

**Comando GPU Tipo 5 (24 bytes):**
```
Offset 0x00: Ponteiro para próximo comando
Offset 0x04: Flags e tipo (0x28000000 | flags)
Offset 0x08: Coordenadas de vértice 1
Offset 0x0c: Coordenadas de vértice 2
Offset 0x10: Coordenadas de vértice 3
Offset 0x14: Ponteiro para dados de textura/cor
```

**Notas:**
- Função otimizada para processar listas encadeadas de polígonos
- Suporta polígonos com número variável de vértices (mínimo 3)
- Usa alinhamento de memória cuidadoso para escrita de comandos GPU
- Implementa culling eficiente usando operações bitwise
- Calcula profundidade para ordenação e seleção de texturas
- Gera comandos diretamente no formato esperado pelo GPU do PS1
- Usa buffer de comandos gerenciado externamente (ordenador de polígonos)

**Otimizações:**
- Processa múltiplos polígonos em um único loop
- Reutiliza cálculos de transformação entre vértices
- Usa operações bitwise para decisões rápidas de culling
- Minimiza acesso à memória através de cache de valores

**Casos de Uso:**
- Rendering de objetos 3D com múltiplos polígonos
- Processamento de malhas de polígonos complexas
- Geração eficiente de comandos GPU para cenas 3D
- Rendering de objetos com número variável de faces
