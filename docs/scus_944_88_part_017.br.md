4. **Recursão:**
   - Empilha dados na pilha de subdivisão
   - Chama recursivamente para cada sub-polígono
   - Desempilha quando recursão completa

5. **Rendering Final:**
   - Quando critério de parada é atingido, renderiza polígono
   - Gera comandos GPU apropriados
   - Atualiza buffers de rendering
