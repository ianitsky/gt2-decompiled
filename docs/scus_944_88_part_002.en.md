### FUN_80061798

**Lines:** 171-2239  
**Type:** `void FUN_80061798(int param_1, undefined4 param_2)`

**Description:**  
Main 3D polygon rendering function. Processes multiple polygon types (triangles, quadrilaterals), applies transformations, performs culling, calculates depth, and generates rendering commands for PlayStation GPU.

**Parameters:**
- `param_1`: Pointer to structure containing 3D object data
  - Offset 0x14: Pointer to transformed vertices
  - Offset 0x18: Pointer to triangle list
  - Offset 0x1c: Pointer to quadrilateral list (4 vertices)
  - Offset 0x20: Pointer to quadrilateral list (5 vertices)
  - Offset 0x24: Pointer to triangle list with 6 vertices
  - Offset 0x28: Pointer to quadrilateral list (7 vertices)
  - Offset 0x2c: Pointer to quadrilateral list with subdivision
  - Offset 0x30: Pointer to quadrilateral list with advanced subdivision
  - Offset 0x34: Pointer to polygon list with 9 vertices
- `param_2`: Additional transformation matrix

**Dependencies:**
- `FUN_800616c4`: Transforms initial vertices
- Extensive GTE functions for transformations, clipping, and depth calculations
- Global variables `DAT_1f800070` (vertices), `DAT_1f800068` (command buffer), `DAT_1f800064` (texture table)

**Processing:**

1. **Initial Transformation:**
   - Calls `FUN_800616c4` to transform base vertices
   - Configures GTE transformation matrix

2. **Triangle Processing (offset 0x1c):**
   - For each triangle:
     - Loads 3 vertices into GTE
     - Applies transformation `gte_rtpt_b()`
     - Performs culling using `gte_nclip_b()`
     - Calculates Z depth for sorting
     - If visible, generates rendering command (type 4 or 7)
     - Calculates texture coordinates based on depth

3. **Quadrilateral Processing (offset 0x20):**
   - Similar to triangles, but with 4 vertices
   - Uses `gte_rtps_b()` for 4th vertex
   - Generates type 5 or 9 commands

4. **Complex Polygon Processing:**
   - Processes polygons with 6, 7, 9 or more vertices
   - Applies recursive subdivision for large polygons
   - Uses depth threshold (0x480, 0x800) to decide subdivision

5. **Recursive Subdivision:**
   - For very large or distant polygons:
     - Divides polygon into smaller sub-polygons
     - Calculates edge midpoints
     - Interpolates colors and texture coordinates
     - Recursively processes each sub-polygon

**Notes:**
- Extremely complex function (~2000 lines)
- Supports multiple 3D primitive types
- Implements LOD (Level of Detail) through subdivision
- Uses depth sorting for correct rendering
- Generates GPU commands directly in memory buffer
- Implements frustum culling and back-face culling

## Polygon Subdivision Module

This module implements recursive subdivision algorithms to improve visual quality and performance.

### Subdivision Algorithm

1. **Necessity Detection:**
   - Checks polygon depth
   - Compares with threshold (0x480, 0x800)
   - Checks size in pixels

   - Calculates polygon center point
   - Creates sub-polygons connecting points

3. **Interpolation:**
   - Interpolates vertex coordinates
   - Interpolates RGB colors
   - Interpolates texture UV coordinates

4. **Recursive Processing:**
   - Recursively processes each sub-polygon
   - Continues until threshold is reached

- Reduces aliasing on large polygons
- Maintains performance through adaptive LOD
