**Tipo:** `void FUN_8006155c(int param_1, int param_2, uint param_3)`

**Descrição:**

**Parâmetros:**
- `param_1`: Ponteiro para estrutura de destino

**Notas:**

- Aplica shifts para posicionar bits corretamente no formato GPU
- Formato final: `(R << 3) | (G << 6) | (B << 9)`

### FUN_80061798

**Linhas:** 171-2239  
**Tipo:** `void FUN_80061798(int param_1, undefined4 param_2)`

**Descrição:**  
Função principal de rendering de polígonos 3D. Processa múltiplos tipos de polígonos (triângulos, quadriláteros), aplica transformações, realiza culling, calcula profundidade e gera comandos de rendering para o GPU do PlayStation.

**Parâmetros:**
- `param_1`: Ponteiro para estrutura contendo dados de objeto 3D
  - Offset 0x14: Ponteiro para vértices transformados
  - Offset 0x18: Ponteiro para lista de triângulos
  - Offset 0x1c: Ponteiro para lista de quadriláteros (4 vértices)
  - Offset 0x20: Ponteiro para lista de quadriláteros (5 vértices)
  - Offset 0x24: Ponteiro para lista de triângulos com 6 vértices
  - Offset 0x28: Ponteiro para lista de quadriláteros (7 vértices)
  - Offset 0x2c: Ponteiro para lista de quadriláteros com subdivisão
  - Offset 0x30: Ponteiro para lista de quadriláteros com subdivisão avançada
  - Offset 0x34: Ponteiro para lista de polígonos de 9 vértices
- `param_2`: Matriz de transformação adicional

**Dependências:**
- `FUN_800616c4`: Transforma vértices iniciais
- Funções GTE extensivas para transformações, clipping e cálculos de profundidade
- Variáveis globais `DAT_1f800070` (vértices), `DAT_1f800068` (buffer de comandos), `DAT_1f800064` (tabela de texturas)

**Processamento:**

1. **Transformação Inicial:**
   - Chama `FUN_800616c4` para transformar vértices base
   - Configura matriz de transformação GTE

2. **Processamento de Triângulos (offset 0x1c):**
   - Para cada triângulo:
     - Carrega 3 vértices no GTE
     - Aplica transformação `gte_rtpt_b()`
     - Realiza culling usando `gte_nclip_b()`
     - Calcula profundidade Z para ordenação
     - Se visível, gera comando de rendering (tipo 4 ou 7)
     - Calcula coordenadas de textura baseadas em profundidade

3. **Processamento de Quadriláteros (offset 0x20):**
   - Similar a triângulos, mas com 4 vértices
   - Usa `gte_rtps_b()` para 4º vértice
   - Gera comandos tipo 5 ou 9

4. **Processamento de Polígonos Complexos:**
   - Processa polígonos com 6, 7, 9 ou mais vértices
   - Aplica subdivisão recursiva para polígonos grandes
   - Usa threshold de profundidade (0x480, 0x800) para decidir subdivisão

5. **Subdivisão Recursiva:**
   - Para polígonos muito grandes ou distantes:
     - Divide polígono em sub-polígonos menores
     - Calcula pontos médios de arestas
     - Interpola cores e coordenadas de textura
     - Processa recursivamente cada sub-polígono

**Notas:**
- Função extremamente complexa (~2000 linhas)
- Suporta múltiplos tipos de primitivas 3D
- Implementa LOD (Level of Detail) através de subdivisão
- Usa ordenação por profundidade para rendering correto
- Gera comandos GPU diretamente em buffer de memória
- Implementa frustum culling e back-face culling

### FUN_80063ef4 (RenderMeshWithSubdivision)

**Nome sugerido:** `RenderMeshWithSubdivision`

**Linhas:** 2272-4987  
**Tipo:** `void FUN_80063ef4(ushort *param_1, undefined4 param_2, uint param_3, uint param_4)`

**Descrição:**  
Renderiza um mesh 3D com subdivisão adaptativa de polígonos. Projeta vértices via GTE, transforma (FUN_800616c4), processa listas de polígonos com backface culling e ordenação por profundidade. Subdivide polígonos grandes/distantes para Gouraud shading. Escreve comandos GPU no buffer.

**Parâmetros:**
- `param_1`: Ponteiro para estrutura de objeto 3D
  - Offset 0x0: Contador de vértices
  - Offset 0x2: Contador de triângulos
  - Offset 0x4: Contador de quadriláteros (4 vértices)
  - Offset 0x6: Contador de quadriláteros (5 vértices)
  - Offset 0x8: Contador de triângulos (6 vértices)
  - Offset 0xa: Contador de quadriláteros (7 vértices)
  - Offset 0xc: Contador de quadriláteros com subdivisão
  - Offset 0xe: Contador de quadriláteros avançados
  - Offset 0x10: Contador de polígonos de 9 vértices
  - Offset 0x12: Contador de polígonos de 10 vértices
  - Offset 0xe: Ponteiro para vértices SVECTOR
  - Offset 0x14: Ponteiro para vértices transformados
  - Offset 0x18-0x34: Ponteiros para listas de polígonos
- `param_2`: Matriz de transformação
- `param_3`: Parâmetro de profundidade ou threshold
- `param_4`: Parâmetro adicional de configuração

**Dependências:**
- `FUN_800616c4`: Transformação inicial de vértices
- Funções GTE para todas as operações de transformação
- Variáveis globais para buffers de trabalho

**Processamento:**

1. **Fase de Transformação Inicial:**
   - Transforma todos os vértices usando GTE
   - Armazena coordenadas transformadas em buffer temporário
   - Calcula flags de visibilidade para cada vértice

2. **Processamento de Polígonos Simples:**
   - Processa triângulos e quadriláteros básicos
   - Aplica culling e gera comandos de rendering

3. **Subdivisão Adaptativa:**
   - Para polígonos grandes ou distantes:
     - Calcula pontos médios de arestas
     - Interpola coordenadas, cores e texturas
     - Divide polígono em 4 sub-polígonos (para quadriláteros)
     - Processa recursivamente cada sub-polígono
   - Continua subdivisão até polígonos serem pequenos o suficiente

4. **Otimizações:**
   - Usa threshold de profundidade para evitar subdivisão desnecessária
   - Verifica flags de visibilidade antes de processar
   - Implementa early-out para polígonos fora da tela

**Notas:**
- Função extremamente complexa (~2700 linhas)
- Implementa sistema completo de LOD adaptativo
- Suporta subdivisão recursiva até 4 níveis
- Otimizada para performance no hardware limitado do PS1
- Gera comandos GPU otimizados para cada tipo de polígono

## Módulo de Processamento de Polígonos

Este módulo gerencia o processamento de diferentes tipos de primitivas 3D.

### Tipos de Polígonos Suportados

1. **Triângulos (3 vértices):**
   - Tipo mais básico
   - Comando GPU tipo 4 ou 7
   - Processamento direto sem subdivisão

2. **Quadriláteros (4 vértices):**
   - Divididos em 2 triângulos
   - Comando GPU tipo 5 ou 9
   - Podem ter subdivisão se muito grandes

3. **Polígonos Complexos (5-10 vértices):**
   - Requerem subdivisão
   - Processados recursivamente
   - Otimizados para objetos detalhados

### Operações de Culling

- **Back-face Culling:** Remove polígonos virados para trás usando produto vetorial
- **Frustum Culling:** Remove polígonos fora da tela usando flags de visibilidade
- **Depth Culling:** Remove polígonos muito distantes ou muito próximos

## Módulo de Subdivisão de Polígonos

Este módulo implementa algoritmos de subdivisão recursiva para melhorar qualidade visual e performance.

### Algoritmo de Subdivisão

1. **Detecção de Necessidade:**
   - Verifica profundidade do polígono
   - Compara com threshold (0x480, 0x800)
   - Verifica tamanho em pixels

2. **Divisão:**
   - Calcula pontos médios de todas as arestas
   - Calcula ponto central do polígono
   - Cria sub-polígonos conectando pontos

3. **Interpolação:**
   - Interpola coordenadas de vértices
   - Interpola cores RGB
   - Interpola coordenadas UV de textura

4. **Processamento Recursivo:**
   - Processa cada sub-polígono recursivamente
   - Continua até threshold ser atingido
   - Limita profundidade de recursão

### Benefícios

- Melhora qualidade visual de objetos distantes
- Reduz aliasing em polígonos grandes
- Mantém performance através de LOD adaptativo
- Suaviza superfícies através de interpolação

- `DAT_1f800064`: Tabela de texturas/cores

- `DAT_1f800398`: Flag de inversão de culling
- `DAT_1f800399`: Máscara de flags para texturas

### Formatos de Comando GPU

Os comandos gerados seguem o formato do GPU do PlayStation:

- **Tipo 4:** Triângulo simples com textura
- **Tipo 5:** Quadrilátero simples
- **Tipo 6:** Triângulo com múltiplas texturas
- **Tipo 7:** Triângulo com textura e cor
- **Tipo 9:** Quadrilátero com textura e cor
- **Tipo 0xc:** Polígono complexo com múltiplas texturas

Cada comando inclui:
- Coordenadas de vértices (SXY)
- Coordenadas de textura (UV)
- Cores (RGB)
- Ponteiros para dados de textura
- Flags de rendering
