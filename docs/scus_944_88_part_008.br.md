# Documentação do Arquivo scus_944.88_part_008.c

## Visão Geral

Este documento descreve todas as funções presentes no arquivo `scus_944.88_part_008.c`, que contém código decompilado do Gran Turismo 2 para PlayStation 1. Este arquivo contém funções relacionadas a utilitários matemáticos, sistema de tipos C++, decodificação de vídeo (MDEC), sistema de memória card, controle de entrada (gamepad) e sistema de CD-ROM.

### Fluxo de Inicialização CD-ROM

1. `CdInit` → Inicializa hardware
2. `EVENT_OBJ_90` → Configura hardware
3. `EVENT_OBJ_80` → Configura callbacks
4. Sistema pronto para uso

### Fluxo de Comando CD-ROM

1. `CdControl` → Envia comando
2. `CD_cw` → Processa comando
3. `CD_sync` → Aguarda conclusão
4. Callbacks executados conforme necessário

### Fluxo de Controle Pad

1. `PadInitDirect` → Inicializa estruturas
2. `PadStartCom` → Inicia comunicação
3. `FUN_80087860` → Inicializa porta
4. `FUN_80087c84` → Envia/recebe dados
5. `FUN_80088270` → Valida resposta

### Fluxo de MDEC

1. `DecDCTReset` → Reseta hardware
2. `DecDCTGetEnv` → Obtém configuração
3. `DecDCTin` → Envia dados
4. `DecDCTout` → Recebe dados decodificados
5. `DecDCTinSync` / `DecDCToutSync` → Aguarda conclusão

## Notas Finais

Este arquivo contém código altamente especializado para múltiplos sistemas do PlayStation 1 no Gran Turismo 2. As funções demonstram:

- Sistema completo de tipos C++ com suporte a RTTI (Runtime Type Information)
- Sistema de decodificação de vídeo MDEC com DMA e callbacks
- Sistema completo de memória card com patches e inicialização
- Sistema avançado de controle (gamepad) com comunicação serial complexa
- Sistema completo de CD-ROM com múltiplos modos de operação e callbacks
- Utilitários matemáticos para conversões e divisão de 64 bits

O código mostra uma arquitetura bem estruturada com separação clara entre sistemas, otimizada para o hardware específico do PlayStation 1, incluindo gerenciamento de interrupções, DMA, timers e comunicação serial.
