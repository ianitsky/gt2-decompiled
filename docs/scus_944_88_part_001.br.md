## Módulo de Sistema de Arquivos/CD-ROM

Este módulo contém funções relacionadas à leitura de arquivos do CD-ROM, descompressão de dados e parsing de estruturas de arquivo.

### load_gt2_overlay_file (LoadGT2OverlayFile)

**Linhas:** 29-73  
**Tipo:** `void load_gt2_overlay_file(int *param_1)`

**Descrição:**  
Carrega o arquivo principal de overlay `gt2.ovl` do CD-ROM. Abre via ISO 9660, aloca buffer, copia dados compactados. Usado como callback de loader por FUN_80082fac. Ver `docs/OVERLAY_LOADING.br.md`.

**Parâmetros:**
- `param_1`: Ponteiro para array de 3 inteiros que armazena informações sobre o arquivo carregado
  - `param_1[0]`: Offset do arquivo em relação ao endereço base
  - `param_1[1]`: Tamanho descomprimido do arquivo
  - `param_1[2]`: Ponteiro para o buffer de descompressão (ou 0 se usar buffer local)

**Dependências:**
- `FUN_8001146c`: Abre arquivo do CD-ROM
- `FUN_8008d0d0`: Aloca buffer de descompressão
- `FUN_8007ab74`: Copia dados do CD para memória
- `FUN_8008cfe0`: Copia dados do buffer de descompressão para destino final

**Notas:**
- Se a alocação de memória falhar, usa um buffer local de 0x30 bytes
- Atualiza variáveis globais `DAT_801c93e0` e `DAT_801c93d0`

### FUN_80010f5c (LoadPrimaryVolumeDescriptor)

**Linhas:** 873-982  
**Tipo:** `undefined4 FUN_80010f5c(undefined4 *param_1)`

**Descrição:**  
Carrega e analisa o Primary Volume Descriptor (PVD) ISO 9660 do CD-ROM. Inicia no setor 16, valida o identificador "CD001" e, ao encontrar o PVD (tipo 0x01), copia o Root Directory Record (34 bytes no offset 0x9c do PVD) para o contexto para resolução de caminhos.

**Parâmetros:**
- `param_1`: Ponteiro para estrutura de contexto de CD que receberá os dados do Volume Descriptor

**Retorno:**
- `0xffffffff` se encontrou o Volume Descriptor Primary, `0xffffffff` com flag de erro se não encontrou

**Dependências:**
- `FUN_80010f1c`: Lê setores do CD
- `strncmp`: Compara strings para validar assinatura "CD001"

**Notas:**
- Começa a busca no setor 16 (padrão ISO 9660)
- Copia dados do Volume Descriptor para offsets 0x22 e 0x0 da estrutura
- Define flag de erro em `param_1[0x11]` se não encontrar
